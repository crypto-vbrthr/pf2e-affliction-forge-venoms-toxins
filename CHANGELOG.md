# Changelog

## 0.1.0

- Initial release.
- Added 32 original poison afflictions covering levels 0-20.
- Added natural venoms, contact poisons, ingested toxins, inhaled toxins, and alchemical weapon poisons.
- Added 7 charge-aware injury-poison coatings for the Affliction Forge weapon/attack workflow.
- Added German and English localization.
- Added semantic Creature Forge tags to every poison.
- Kept innate natural venoms separate from consumable injury-poison coating semantics.
- Added provider-library registration through the Affliction Forge public API.
- Added managed world-compendium provisioning and synchronization with the Foundry 14 index-projection fix from Plagues & Pestilence.
- Added portable contract tests with sibling-module discovery and `PF2E_AFFLICTION_FORGE_PATH` override.
- Added regression tests for schema validity, localization, level/DC balance, unique identities, semantic-tag vocabulary, injury-poison semantics, startup synchronization, and portable test imports.
